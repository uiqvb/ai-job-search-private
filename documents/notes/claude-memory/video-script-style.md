**Format (2026-10-27):** every script is a `Storyboard.md` table (Time | Pointers | Example line | You do | On screen | Sound, ~1 min, running gag) plus a keyword `Filming Sheet.txt`, modelled on `documents/video/infosys/`. Never a section-by-section prose script; he rejected that for Tesla ("I don't want this sort of script"). `/video script <company>` does this.

Before writing or editing any intro-video script, read `documents/video/SCRIPT-RULES.md` and follow it. Core points: one (max two) achievement chosen for the company, told with setup → problem → result; every sentence starts from what was just said (his fix: "It's powered by an Arduino that..."); spoken, casual; keep his own edits (typo fixes only).

**Why:** Manit (2026-10-21) rejected crowded, list-like scripts as "super unnatural" with no "proper pretext", and rewrote a line himself to fix a hard transition.

**How to apply:** add any new correction he gives to SCRIPT-RULES.md in the same turn. Related: [[intro-video-outreach]]
