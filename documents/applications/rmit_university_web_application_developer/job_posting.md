About the role: Activities for this casual role include providing support with conversion of an Excel-based game simulation into a web application. Key tasks may include: Translate the existing Excel-based simulation, game mechanics, investment decisions, scoring and progression into an intuitive, responsive web application. Convert and implement the simulation logic by translating the existing formulas, rules and game mechanics into reliable web-based application logic. Assist learning designers and academics to improve the interface, dashboards and interactive features. Additional duties as required.

Skills / Experience: Demonstrated experience developing and deploying web applications. Strong skills in modern web application development, including experience with relevant programming languages, frameworks and development tools. Knowledge of Programming Languages like Javascript and HTML preferred. Experience translating complex business logic, formulas or existing systems into web-based applications. Sound understanding of user experience and interactive interface design. Demonstrated ability to work collaboratively with non-technical stakeholders. Experience with testing, debugging and maintaining web applications.

Reporting Line: Reports to Senior Learning Designer

Engagement Type: This role is engaged on a casual, as-required basis. There is no guarantee of ongoing or regular work. Hours will vary depending on operational requirements.

Qualifications: A relevant tertiary qualification in Computer Science, Software Engineering, Information Technology or Web Development
